A modern, responsive travel website template featuring:
- Hero banner with promotional section
- Explore More section with travel cards
- Pricing table for travel packages
- Mobile-friendly navigation with animated hamburger menu
- Glassmorphism and ripple UI effects
- Robust JavaScript for interactivity and modal overlays


## Features
- Responsive design for desktop and mobile
- Consistent navigation bar color and white text
- Animated mobile menu toggle
- Pricing and promo sections with max-width constraints
- Timeline progress and notification system

## File Structure
- `Hero.html` — Main HTML file with all sections
- `styles.css` — Custom styles for layout, responsiveness, and effects
- `script.js` — JavaScript for navigation, modals, ripple effects, and more

## Usage
1. Open `Hero.html` in your browser.
2. Customize content, images, and pricing as needed.
3. Edit `styles.css` for branding and color changes.
4. Update `script.js` for custom interactivity.

## Customization
- Change colors and fonts in `styles.css`.
- Add or remove travel cards and pricing options in `Hero.html`.
- Extend JavaScript features in `script.js` as needed.
